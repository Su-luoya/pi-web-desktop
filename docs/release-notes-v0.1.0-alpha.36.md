# Pi Web Desktop 0.1.0-alpha.36（build 36）— Apple Silicon alpha（未公证）

## 摘要

本版修复 Pi CLI 与 Pi extensions 的更新流程，不包含手机访问或服务管理的新功能。

- **修复 Home 展示路径导致更新计划被拒绝。** 执行前将 `~/` 还原为当前用户 Home，再应用原有路径白名单，并拒绝任一层的 `.` / `..` 路径段；展示和日志仍然脱敏。
- **识别 Pi 官方安装器与用户级 npm 扩展。** CLI 核对启动器、活动版本记录与 release 包元数据；扩展兼容当前 `pi list` 的包名加安装路径格式，从实际安装位置读取版本，不再要求列表直接给出“包名@版本”。
- **确认与进度统一到「更新进度」窗口。** 长说明可滚动、动作固定在底部；回车或关闭待确认窗口取消，只有点击「确认更新」才执行，重复确认不会重复启动命令。
- **批量扩展更新按整批汇总。** 显示逐包序号，保留跨包日志，不会在第一个包成功后提前结束；部分失败保留原因。更新后版本复查同样还原 Home 展示路径，避免成功后误报版本未知。

## 更新流程与边界

### Pi CLI

- 支持已验证的 npm / pnpm 全局安装，以及本版新增识别的官方安装器布局；无法验证的来源仍只提供手动入口。
- 官方安装器识别检查活动版本记录、对应 release 的包名、版本与可执行文件；这里的“已验证”只指本机安装形态证据，不代表校验了上游代码签名或发行来源。
- 执行仍通过可执行文件与参数数组调用 `update --self`，不使用 shell 字符串、不调用 `sudo`。
- 启动前自动更新仍默认关闭，只在原有目标版本与进程保护条件均满足时执行；手动更新仍要求显式确认与风险说明。

### Pi extensions

- 当前 `pi list` 的 `User packages:` 列表按包名与实际安装路径配对，再读取并核对安装目录的 `package.json`；保留旧版列表的兼容解析。
- 执行范围为已验证的 npm 全局或 Pi 用户级 npm 扩展；项目级、固定版本或版本范围、git 与本地扩展不纳入本次受管 npm 更新范围。
- 扩展更新必须由用户确认，运行中的 Pi 或进程状态不确定仍阻止执行；确认后、执行前再次检查。
- 安装后从同一 Pi 可执行路径重新检测版本；命令失败、版本不达标或无法验证时不声称成功，也不声称已执行文件回滚。

### 确认与执行窗口

- 只读说明、待确认计划与执行状态复用现有「更新进度」窗口，长内容留在滚动区，不再撑大系统对话框。
- 待确认时不会执行更新；回车、取消或关闭窗口均取消。点击确认后动作只消费一次，继续在同一窗口显示执行阶段与日志。
- 批量扩展显示 `1/2`、`2/2` 等序号，最后统一显示完成或部分失败；中间单包成功不会触发整批成功或提前关窗。
- 执行开始后关闭窗口只隐藏界面，不中止更新；可由菜单重新打开。应用不会为更新而自动结束或接管 Pi 会话。

## 未变的部分与已知限制

- 桌面应用更新仍为 appcast 优先、GitHub API 回落；没有新增联网域名、数据位置、第三方运行时依赖或 schema 迁移。发布检查将 appcast 工作流的 checkout@v4 固定到同一版本对应的完整提交 SHA，未升级 Actions 版本。
- Pi 扩展不提供无人值守更新；缓存回退的版本信息仍不给执行入口。
- 验证只覆盖本机路径、版本、包名与既有检查，不校验上游代码签名或安装包内容；第三方扩展代码拥有 Pi 会话的系统访问权限。
- 未做真实 CLI / 扩展更新的端到端安装验证，隔离测试不能证明任意本机安装布局或第三方包都能升级成功。
- 未用 VoiceOver 逐项朗读核验，未做本次 tailnet 访问回归，也未在另一台 Mac 上验证首次安装或 Gatekeeper 放行。
- 产物仍为 **Apple Silicon、macOS 26+、ad-hoc 签名、未公证的 alpha prerelease**，不支持 Intel，不是稳定版。

## 安装、校验与回退

下载本版 Release 的 ZIP 与同名 `.sha256`，运行：

```sh
shasum -a 256 -c Pi-Web-Desktop-0.1.0-alpha.36+build.36.zip.sha256
```

解压后将 `Pi-Web-Desktop.app` 放入 `/Applications`。首次打开可能需要在“系统设置 → 隐私与安全性”中仅针对该应用放行，或在 Finder 中右键打开；不需要也不建议关闭 Gatekeeper。

本版没有数据迁移。如需回退，退出应用并用 [alpha.35 的 ZIP](https://github.com/Su-luoya/pi-web-desktop/releases/tag/v0.1.0-alpha.35) 替换应用包；原有服务数据不随应用包替换。维护者可从 appcast 移除本版条目以停止推送；应用内安装器不提供自动降级。
